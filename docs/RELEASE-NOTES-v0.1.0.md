# Goblin-Logic-Manager v0.1.0

## Pioneer release

The first Goblin release converts the original GLM-5.3 OpenCode developer prompt into a small model-expandable repository.

### Included

- model-neutral development core
- GLM-5.3 pioneer overlay
- generated OpenCode custom agent
- repo-level `AGENTS.md`
- JSON model registry
- reserved Qwen, DeepSeek, and Kimi family slots
- stdlib-only Python renderer
- stdlib-only verification script
- Android, Chrome/browser, Xubuntu/Linux, small-app, UI, Git-safety, and evidence-first development rules
- model-adapter documentation

### Architectural promise

Goblin's development rules are stable.

Model-specific prompt tuning is replaceable.

### Explicit non-claims

Qwen, DeepSeek, and Kimi are **not** tuned or verified in v0.1.0.

Their registry entries reserve clean extension points only.
