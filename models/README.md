# Model overlays

Model overlays contain **only behavior that is genuinely model-family-sensitive**.

The shared development philosophy belongs in `core/developer-core.md`.

## Current state

- `glm-5.3.md` — pioneer overlay, active.
- Qwen — reserved in the registry; no tuning claim yet.
- DeepSeek — reserved in the registry; no tuning claim yet.
- Kimi — reserved in the registry; no tuning claim yet.

A reserved family should not receive a copied GLM prompt and be labeled supported.

Promotion requires actual tuning evidence.
